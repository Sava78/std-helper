## Общее описание

std-helper — расширение для Visual Studio Code. Оно подставляет `std::` вместо символа `§`, чтобы не набирать префикс стандартной библиотеки C++ вручную.

Расширение запускается вместе с редактором и следит за вводом в открытом файле.

## Возможности

- Заменяет каждый введённый символ `§` на текст `std::`.
- Срабатывает сразу во время набора, без отдельной команды.
- Работает в любом открытом файле.

## Пример

Было:

```cpp
§cout << "hello";
```

Стало:

```cpp
std::cout << "hello";
```

## Как пользоваться

1. Установите расширение и откройте файл в VS Code.
2. Поставьте курсор в нужное место.
3. Напечатайте `§`.
4. На месте символа появится `std::`.
